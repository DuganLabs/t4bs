# Security Policy

## Reporting a vulnerability

Please email `warren@greenput.com` with details. Encrypt with [age](https://github.com/FiloSottile/age) using the recipient key in `.security/age-pubkey` if present.

We aim to acknowledge within 72 hours. Coordinated disclosure preferred.

## Supported versions

Latest published release of this repository's primary artifact (the deployed site, the main npm tag, etc.). Older releases receive critical fixes only when feasible.

## Scope

Anything in this repository's code or its production deployment. Out of scope: third-party services this project integrates with — please report those upstream.
